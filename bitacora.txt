Punto 6: Función de HTML, CSS y JavaScript
Roles: 
- html: Este me le va a dar la estructura a la pagina, donde ira cada texto y cada parametro de la pagina, estos parametros y estructura seran aprobadas basadas en las peticiones del cliente.
   Ejemplo: El cliente quiere que el titulo grande sea Rueda con nosotros, y a los lados halla subtitulos y descripciones con sus funcionalidades, esa estructura se la daremos con el html.
- CSS: Este me le dara vida a la pagina web, con la estructura lista, le damos colores y rasgos para que sea vea mejor visualmente , acorde a los gustos del cliente.
   Ejemplo: El cliente quiere que los subtitulos sean en cursiva y su tono sea azul oscuro con un fondo gris. Eso se lo daremos con nuestro CSS.
- JavaScript: Este le permite agregar interactividad y funcionalidades a una página web. Por ejemplo, puede validar los datos de un formulario de reserva, mostrar mensajes al usuario o actualizar información de la página.
   Ejemplo: El cliente quiere validar los datos de un formulario de reserva, mostrar mensajes al usuario o actualizar información de la página con JavaScript lo puede hacer.
   

Mini-reto 2: La vitrina de Rueda Libre
La página contiene:
- Un encabezado con el nombre del negocio y un menú de navegación.
- Una sección «¿Quiénes somos?» para presentar la empresa.
- Una sección «Nuestros servicios» con información sobre el alquiler de bicicletas, los recorridos guiados y el taller básico.
- Listas para mostrar los beneficios de los servicios.
- Una lista ordenada con los pasos para alquilar.
- Imágenes relacionadas con el negocio.
- Un enlace externo a la ubicación en Google Maps.
- Un enlace de correo electrónico mediante mailto.
- Un enlace interno para llegar a la sección Encuéntranos.
- También utilicé footer para organizar mejor el contenido de pie de pagina.


Mini-reto 3: Tarifas claras — Tablas y rutas relativas
En este mini-reto creé la página tarifas
-La página contiene dos tablas:
   Una tabla con las tarifas de alquiler de bicicletas según el tipo de bicicleta y el tiempo de alquiler.
   Una tabla con los recorridos, sus distancias, duración, nivel y precio por persona.
- Para organizar las tablas utilicé caption, thead, tbody y las etiquetas th con el atributo scope, para identificar los encabezados de las filas y columnas.
- También agregué información sobre los elementos incluidos en las tarifas, los horarios de los recorridos y lo que deben llevar los usuarios.
- Utilicé rutas relativas para mostrar una imagen desde la carpeta img y para conectar las páginas. Desde la página principal agregué un enlace directo a la tabla de recorridos utilizando un identificador.


Mini-reto 4: Rueda Libre v0.1 — Sitio navegable
En este mini-reto creé la página paginas/reservas.html, donde inclui el título Reserva tu bicicleta, un enlace de correo electrónico y los horarios de atención organizados con dl, dt y dd.
También agregué un menú de navegación y un pie de página con el nombre del negocio, el correo electrónico y el año en las tres páginas.
El menú permite navegar entre Inicio, Tarifas y rutas, y Reservas. Agregué enlaces para reservar desde la página principal y desde la página de tarifas.

Las rutas relativas permiten conectar las páginas por la ubicación de cada archivo. Cuando el archivo de destino está dentro de una carpeta se escribe el nombre de esa carpeta y luego el del archivo. Cuando se necesita regresar a la carpeta anterior, se utiliza ../.
